## Обо мне

Привет! Я Роман, занимаюсь разработкой и развиваю собственные проекты

Всё началось с небольших ботов для ВКонтакте, позже переключился на Telegram. Сейчас разрабатываю разные сервисы: от ботов и Mini Apps до полноценных веб-приложений с API, базами данных и платёжными системами

Основной язык программирования JavaScript, работаю с Node.js, также использую Python. Сам настраиваю серверы, занимаюсь инфраструктурой, почтовыми системами и всем, что необходимо для работы проектов

Мне интересно не просто написать код, а довести идею до работающего продукта, которым действительно можно пользоваться
